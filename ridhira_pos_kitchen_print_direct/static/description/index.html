Installation & Configuration Guide

Follow these simple steps to install the module in Odoo and configure the external Python print proxy.

I. Module Deployment and Installation

A. Odoo Module Placement

The module folder (ridhira_pos_kitchen_print_direct) must be placed in your Odoo custom addons directory.

.../custom_addons/ridhira_pos_kitchen_print_direct/__manifest__.py

B. Configuration & Installation

  1. Log in to Odoo as Administrator.
  2. Activate Developer Mode (Settings > General Settings).
  3. Go to Apps and click Update Apps List.
  4. Search for Ridhira POS Kitchen Print Direct and click Install.

II. Configure the External Print Proxy

The external Python proxy must run on a machine (POS device, Raspberry Pi, or PC) that has network access to your printers.

1. Obtain the Proxy Application

The print proxy is available as a standalone executable application for Windows, Linux, and macOS. There is no need to install Python or any dependencies manually.

Note: We will provide the proxy binary for your relevant Operating System along with your API Key via WhatsApp, Telegram chat, or Email.

2. Run the Proxy Server

  • Windows: Simply double-click the provided app.exe file. A command prompt window will open indicating the server is running. You can optionally create a shortcut in your Startup folder to run it automatically on boot.
  • Linux: Add execute permissions using chmod +x app_linux and run it via terminal ./app_linux. We recommend setting it up as a systemd background service for production.
  • macOS: Open the terminal, grant execute permissions using chmod +x app_mac, and run it with ./app_mac.

3. Verify Connection & Dashboard

  • Live Dashboard: Navigate to http://127.0.0.1:9100 to manage your print queues.
  • Detect Printers: API access available at http://127.0.0.1:9100/detect

4. Configure Odoo POS Settings (Kitchen Printers)

  1. Navigate to Point of Sale > Configuration > Settings.
  2. Scroll to Preparation Printers and enable the checkbox.
  3. Click the Printers link and Create a new printer.
  4. Printer Name: Give it the exact name you configured in printers.json (e.g. "Kitchen_Printer").
  5. Printer Type: Select "Use an Epson printer".
  6. Epson Printer IP Address: Enter the IP address of the machine running the Python proxy (e.g., 192.168.1.100).
  7. (Optional) If this is a Boba/Sticker printer, check "Is a Cup Label Printer". You can configure canvas sizes and easily toggle "Print Price on Label" on or off.
  8. Click Save.

5. Configure the Main Receipt Printer

  1. Go to Point of Sale ‣ Configuration ‣ Settings.
  2. Scroll to the Connected Devices section and check the box for ePos Printer.
  3. ePos Printer IP Address: Enter the IP address of the machine running the Python proxy (e.g., 192.168.1.100).
  4. Note: Main receipt jobs will automatically route to the "POS_Printer" queue in your proxy.
Setting Changes for POS Terminal Browser (Mixed Content)
If your Odoo instance is hosted on HTTPS, but the proxy is on HTTP, browsers will block the connection.

You must configure the specific browser on the POS terminal to allow insecure content for your Odoo domain (in Chrome, this is under Site Settings > Insecure content > Allow). Apply this to whichever browser you use to access the POS terminal.

III. Testing & Troubleshooting

  • Open Session: Launch a new POS session.
  • Order: Process an order with products marked as "Send to Kitchen".
  • Verify: Check your Dashboard (`http://127.0.0.1:9100`) to see the job instantly queued and printed.
Support Note: If a job fails, you can visually click "Retry" directly from your Dashboard!
